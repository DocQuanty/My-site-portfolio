What I do

RAG on local models

RAG на локальних моделях

Qdrant and pgvector retrieval, e5/bge-m3 embeddings, query expansion, semantic deduplication — served by Ollama, no data leaves the network.

Пошук у Qdrant і pgvector, ембедінги e5/bge-m3, розширення запитів, семантичний дедуп — усе на Ollama, дані не виходять за межі мережі.

Agents with a human in the loop

Агенти з людиною в контурі

Structured output, tool use, MCP servers, confirmation before any irreversible action. Telegram as the interface people already have open.

Структуровані відповіді, виклик інструментів, MCP-сервери, підтвердження перед незворотною дією. Telegram як інтерфейс, який у людей уже відкритий.

Evaluation before release

LLM-as-judge benchmarks, NER model comparisons, versioned prompt registries. Model choices backed by numbers, not vibes.

Бенчмарки LLM-as-judge, порівняння NER-моделей, реєстри промптів із версіями. Вибір моделі — за числами, не за відчуттями.

Інтерв'ю з клієнтом, ТЗ, комерційна пропозиція — далі FastAPI, Docker, Kubernetes, GitLab CI. Одна людина, яка бачить увесь шлях.
